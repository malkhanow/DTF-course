# Custom Studio — сайт курсов

## Структура (8 html-страниц)
- `index.html` — главная
- `about.html` — «о курсе» (текст из Telegram-канала)
- `pricing.html` — тарифы
- `login.html` — вход для учеников
- `course.html` — программа: 7 глав, 44 урока
- `lesson.html` — страницы уроков
- `create-link.html` — генератор ссылок для «Точки входа» без пароля (твой личный инструмент)
- `admin.html` — **личный кабинет**: выдача доступа клиентам, сохраняется в Google Таблицу

## Настройка личного кабинета (обязательно, иначе он не сохраняет данные)

### Шаг 1 — Google Таблица
Следуй инструкции в конце файла `apps-script-code.txt`: создаёшь таблицу, вставляешь код в Apps Script, разворачиваешь как веб-приложение, получаешь ссылку вида `https://script.google.com/macros/s/.../exec`.

### Шаг 2 — вписать ссылку в 2 файла
Открой `admin.html`, найди в самом низу блок:
```js
const CONFIG = {
  SCRIPT_URL: 'ВСТАВЬ_СЮДА_ССЫЛКУ_НА_APPS_SCRIPT',
  SECRET_TOKEN: 'ВСТАВЬ_СЮДА_СВОЙ_СЕКРЕТНЫЙ_КОД',
  ADMIN_PASSWORD: 'change-me-2026'
};
```
Вставь свою ссылку и секретный код (тот же, что указал в Apps Script на шаге 1), и смени `ADMIN_PASSWORD` на свой пароль для входа в кабинет.

Открой `login.html`, найди строку:
```js
const SCRIPT_URL = 'ВСТАВЬ_СЮДА_ССЫЛКУ_НА_APPS_SCRIPT';
```
Вставь туда ту же ссылку — тогда форма входа учеников будет видеть клиентов, которых ты добавил через кабинет.

Сохрани оба файла и загрузи (push) их на GitHub.

## Как пользоваться кабинетом
Заходишь на `admin.html` → вводишь пароль администратора → заполняешь имя/Telegram/почту клиента → выбираешь тариф (для «Точки входа» появится выбор 2 уроков) → «Создать и выдать доступ» → получаешь готовый логин/пароль → отправляешь клиенту. Всё сразу сохраняется в твою Google Таблицу и видно в списке ниже на той же странице.

## Уже готовые 100 логинов
Помимо кабинета, на сайте уже жёстко зашиты 100 пар логин/пароль (30 «Стандарт», 40 «Профи», 30 «VIP») — они в `credentials.csv`, работают без всякой настройки Google Таблицы.

## Демо-режим
Глава «Введение» открыта всем без входа. Остальное — по тарифу, показывается под блюром с призывом войти/посмотреть тарифы.

## Деплой на GitHub Pages
Загрузи все 8 html-файлов в репозиторий, включи Pages в настройках.
