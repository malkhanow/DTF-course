# Custom Studio — сайт курсов

## Структура (4 страницы)
- `index.html` — главная: логотип Custom Studio + сетка курсов (сейчас один, место под другие)
- `login.html` — отдельная страница входа
- `course.html` — программа курса по DTF-печати: 7 глав, 44 урока
- `lesson.html` — отдельная страница урока (`lesson.html?ch=<глава>&n=<номер урока>`), с хлебными крошками и кнопками «пред./след. урок»

## Весь контент перенесён ✅
Все 44 урока — полный текст, картинки, встроенные видео (RuTube) — перенесены с Teletype прямо в сайт. Переходов на Teletype больше нет ни для одного урока.

## Демо-режим
- **Глава 1 «Введение» (уроки 1.1–1.6) — открыта полностью всем, даже без входа.** Это бесплатный образец курса.
- **Главы 2–7** — без входа видны первые пара абзацев, дальше текст размыт (можно скроллить, но не читается), плашка «Войти» остаётся на виду при прокрутке.
- После входа — всё открывается полностью, без блюра.

## Как проверить
Скачай все 4 html-файла в одну папку, открой `index.html` двойным кликом в браузере. Главная → карточка курса → список глав/уроков → отдельная страница урока.

## Деплой на GitHub Pages
Загрузи все 4 html-файла в репозиторий, включи Pages в настройках.

## Выдача доступа ученикам
Логин/пароль — в `credentials.csv`, уже встроены в код `login.html`. Когда 100 пар закончатся — открой `login.html`, найди массив `VALID_CREDENTIALS`, добавь новую строку, сохрани и запушь на GitHub.
