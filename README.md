# Custom Studio — сайт курсов (готово к загрузке на GitHub)

## Все пароли и настройки уже вписаны — ничего донастраивать не нужно

## Структура (8 html-страниц + 1 таблица)
- `index.html` — главная
- `about.html` — «о курсе»
- `pricing.html` — тарифы
- `login.html` — вход для учеников (подключён к Google Таблице)
- `course.html` — программа: 7 глав, 44 урока
- `lesson.html` — страницы уроков
- `create-link.html` — генератор ссылок «Точка входа» (личный инструмент, никому не давай ссылку на него)
- `admin.html` — личный кабинет: выдача доступа, сохраняется в Google Таблицу
- `credentials.csv` — таблица уже готовых 100 логинов/паролей (30 Стандарт, 40 Профи, 30 VIP)

## Вход в личный кабинет (admin.html)
Заходишь через обычную страницу входа сайта (`login.html`) под своим собственным логином:

**Логин: vladimir**
**Пароль: EeSPlhlis7Xl**

Сайт сам узнаёт этот логин и сразу перебрасывает в личный кабинет — отдельный пароль администратора вводить не нужно.
Сохрани эти данные в надёжном месте (менеджер паролей/заметки).

Если захочешь сменить пароль — открой `login.html`, найди строку с `login: "vladimir"` в самом низу массива `VALID_CREDENTIALS`, замени пароль на свой, сохрани и загрузи файл на GitHub заново.

## Как загрузить на GitHub
1. Зайди в свой существующий репозиторий `DTF-course` на GitHub
2. Загрузи (перетащи или через «Add file» → «Upload files») все 8 html-файлов и `credentials.csv` — можно поверх старых, они заменятся
3. Готово — изменения появятся на сайте через пару минут

## Демо-режим
Глава «Введение» открыта всем без входа. Остальное — по тарифу клиента, показывается заблюренным с призывом войти.

## Как этим пользоваться дальше
- Заходишь на `твой-сайт/admin.html`, вводишь пароль выше
- Заполняешь имя/Telegram/почту клиента, выбираешь тариф
- Нажимаешь «Создать и выдать доступ» — получаешь готовый логин/пароль, отправляешь клиенту
- Данные сразу сохраняются в твою Google Таблицу и видны в списке на той же странице
- Для «Точки входа» (2 урока) — можно как через `admin.html` (там тоже есть выбор), так и через отдельный `create-link.html`, если удобнее ссылкой без пароля
