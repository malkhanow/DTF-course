# Custom Studio — сайт курсов

## Структура (6 страниц)
- `index.html` — главная: логотип + сетка курсов
- `about.html` — «о курсе» (текст из Telegram-канала), знакомство перед покупкой
- `pricing.html` — тарифы
- `login.html` — вход
- `course.html` — программа курса: 7 глав, 44 урока
- `lesson.html` — страница урока с хлебными крошками

## Тарифы и реальное ограничение доступа
Теперь это не только текст на `pricing.html` — доступ действительно проверяется по логину:

- **Стандарт** (4 900 ₽) — логины `student001`–`student030`. Открыты только главы: Введение, Работа с принтером, ЧЗВ.
- **Профи** (12 900 ₽) — логины `student031`–`student070`. Открыт весь курс (все 7 глав).
- **VIP** (24 900 ₽) — логины `student071`–`student100`. Тоже весь курс (разница с «Профи» — личные консультации, это не функционал сайта, а ваше личное время).
- **Точка входа** (350 ₽, 2 урока на выбор клиента) — под эту категорию логины не генерируются заранее, их нужно создавать вручную под каждую продажу (см. ниже).

Все логины и пароли — в `credentials.csv`, с колонкой «тариф».

## Как выдать доступ на «Точку входа» (2 урока на выбор) — без правки кода
Открой `create-link.html` (шестой файл в комплекте, он не привязан к общей навигации сайта и не должен быть виден клиентам). Отметь галочками ровно 2 нужных урока, нажми «Создать ссылку» — получишь готовую ссылку вида:

`https://your-site.github.io/course.html?entry=5.2,5.4`

Просто отправь эту ссылку клиенту (например в Telegram) — открыв её, он сразу увидит эти 2 урока, без пароля и логина. Код трогать не нужно.

Файл `create-link.html` нужно один раз загрузить на GitHub вместе с остальными — он должен физически лежать на сайте, чтобы ссылки работали, просто никому на него не давай прямую ссылку.

## Как добавить обычный логин на существующий тариф
Открой `login.html`, найди массив `VALID_CREDENTIALS`, скопируй строку нужного тарифа и поменяй login/password:
```js
// Стандарт (Введение, Принтер, ЧЗВ):
{ login: "student101", password: "ваш-пароль", tier: "standard", access: { type: "chapters", chapters: [0,1,4] } },
// Профи / VIP (весь курс):
{ login: "student101", password: "ваш-пароль", tier: "profi", access: { type: "chapters", chapters: [0,1,2,3,4,5,6] } },
```

## Демо-режим
Глава «Введение» открыта полностью всем, даже без входа. Остальные главы — по тарифу; без доступа урок показывается целиком под блюром с призывом войти / посмотреть тарифы.

## Как проверить
Скачай все 6 html-файлов в одну папку, открой `index.html` в браузере. Попробуй войти как `student001` (Стандарт) и сравни с логином из блока 031–070 (Профи) — увидишь разницу в доступных главах.

## Деплой на GitHub Pages
Загрузи все 6 html-файлов в репозиторий, включи Pages в настройках.
