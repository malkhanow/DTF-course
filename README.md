# Сайт курса по DTF-печати

## Как выложить на GitHub Pages
1. Создай новый репозиторий на GitHub (или папку в существующем репозитории Custom Studio).
2. Загрузи туда всего 2 файла: `index.html` и `course.html` (всё остальное — стили и логины — уже встроено внутрь них).
3. В настройках репозитория включи GitHub Pages (Settings → Pages → Source: main branch).
4. Через пару минут сайт будет доступен по ссылке вида `https://<твой-логин>.github.io/<репозиторий>/`.

## Как проверить у себя перед загрузкой
Просто дважды кликни на `index.html` — он откроется в браузере (Chrome/Edge/Яндекс.Браузер) как обычная веб-страница, без интернета. Попробуй войти под `student001` (пароль смотри в `credentials.csv`).

Не открывай файл через онлайн-редакторы/просмотрщики кода — они могут не выполнять JavaScript, из-за чего форма входа не будет работать. Открывай именно двойным кликом в браузере.

## Как выдавать доступ ученикам
Все 100 пар логин/пароль лежат в `credentials.csv` (для тебя, с колонками для отметок) — они же встроены в код `index.html`.

Когда человек оплатил:
1. Открой `credentials.csv`.
2. Возьми первую свободную пару, отметь в колонке «выдан» и «кому выдан».
3. Отправь пару ученику.

## Если 100 пар закончились
Открой `index.html`, найди в коде массив `VALID_CREDENTIALS` (ближе к концу файла), добавь новую строку по образцу:
```js
{ login: 'student101', password: 'ваш-пароль' },
```
Сохрани и загрузи (push) обновлённый файл на GitHub.

## Важно понимать про защиту
Пароли хранятся прямо в коде страницы. Это не банковский уровень защиты — человек, который специально откроет исходный код сайта, сможет их увидеть. Но случайный посетитель дальше формы входа не пройдёт.

## Структура
- `index.html` — страница входа (стили и логины/пароли встроены внутрь)
- `course.html` — список из 7 глав / 44 уроков (открывается только после входа), каждый урок ведёт на Teletype
- `credentials.csv` — твоя рабочая таблица для отметок о выдаче доступа
