# Custom Studio — сайт курсов (v3)

## Структура (4 страницы)
- `index.html` — главная: логотип Custom Studio + сетка курсов (сейчас один, место под другие)
- `login.html` — отдельная страница входа
- `course.html` — программа курса по DTF-печати: 7 глав, 44 урока
- `lesson.html` — отдельная страница урока (открывается по ссылке `lesson.html?ch=<глава>&n=<номер урока>`), с хлебными крошками наверх

## Демо-режим
- Урок 1.1 «Добро пожаловать!» открыт полностью всем, даже без входа — это бесплатный образец.
- Остальные уроки: видны первые пара абзацев, дальше текст размыт (можно скроллить, но не читается), сверху — плашка «Войти».
- После входа — всё открывается полностью, без блюра.

## Что уже перенесено полностью
Только 6 уроков главы «Введение» (1.1–1.6) — с полным текстом, картинками и видео, один в один как на Teletype.

Остальные 38 уроков пока показывают заглушку «контент переносится» + ссылку на Teletype. Присылай ссылки следующей главы — перенесу таким же образом.

## Как проверить
Скачай все 4 файла в одну папку, открой `index.html` двойным кликом в браузере. С главной клик по карточке курса → на страницу курса → клик по уроку → полноценная страница урока.

## Деплой на GitHub Pages
Загрузи все 4 html-файла в репозиторий, включи Pages в настройках — без изменений в структуре.
