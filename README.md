# Сайт курса по DTF-печати

## Как выложить на GitHub Pages
1. Создай новый репозиторий на GitHub (или отдельную папку в существующем репозитории Custom Studio).
2. Загрузи туда все файлы из этой папки, сохранив структуру: `index.html`, `course.html`, `css/style.css`, `js/credentials.js`.
3. В настройках репозитория включи GitHub Pages (Settings → Pages → Source: main branch).
4. Через пару минут сайт будет доступен по ссылке вида `https://<твой-логин>.github.io/<репозиторий>/`.

## Как выдавать доступ ученикам
Все 100 пар логин/пароль уже сгенерированы и лежат в `js/credentials.js` (для сайта) и `credentials.csv` (для тебя — таблица для отметок).

Когда человек оплатил:
1. Открой `credentials.csv`.
2. Возьми первую свободную пару логин/пароль, отметь в колонке «выдан» и «кому выдан».
3. Отправь эту пару ученику (например, в мессенджере).

Дополнительных действий на сайте делать не нужно — все 100 пар уже встроены в код.

## Если 100 пар закончились
Открой `js/credentials.js`, добавь новые строки по образцу:
```js
{ login: 'student101', password: 'ваш-пароль' },
```
Сохрани файл и загрузи (push) обновлённую версию на GitHub — изменения появятся на сайте через пару минут.

## Важно понимать про защиту
Пароли хранятся прямо в коде страницы (`js/credentials.js`). Это не банковский уровень защиты — человек, который специально откроет исходный код сайта, сможет их увидеть. Но случайный посетитель дальше формы входа не пройдёт. Если этого недостаточно — можно позже перейти на Supabase/Firebase Auth (обсуждали как запасной вариант).

## Структура
- `index.html` — страница входа
- `course.html` — список из 7 глав / 44 уроков (открывается только после входа), каждый урок ведёт на соответствующую страницу в Teletype
- `css/style.css` — единый стиль обеих страниц
- `js/credentials.js` — список логинов/паролей
- `credentials.csv` — твоя рабочая таблица для отметок о выдаче
